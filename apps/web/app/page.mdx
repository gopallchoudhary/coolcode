# coolcode

Welcome to the **coolcode** documentation — a terminal AI coding agent built with OpenTUI, Hono, and Postgres.

## Getting started

Run the CLI from the repository root:

```bash
bun run dev:cli
```

Start the API server in another terminal:

```bash
bun run dev:server
```

## Next steps

- Explore the packages under `packages/*` (cli, server, database, shared).
- Add more `.mdx` pages under `app/` and they will show up in the sidebar automatically.
